# Site snapshot: 2026-09-24

This directory preserves the complete public site immediately before the redesign.

To restore the snapshot manually, copy `index.html`, `styles.css`, `blogs.html`,
and `BLOG_TEMPLATE.md` from this directory to the repository root, and copy
`posts.js` back to `blogs/posts.js`, then commit the restoration. Git history
also preserves the pre-redesign version.
