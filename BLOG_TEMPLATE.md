# Blog Post Request

Send me a completed copy of this template whenever you want a post added.

```text
Title: Your post title
Date: YYYY-MM-DD
Summary: One sentence for the blog index.
Slug (optional): a-stable-url-for-this-post
Original publication URL (optional): https://example.com/your-post

Body:
First paragraph.

Second paragraph.

Optional links:
- Link text: https://example.com
```

I will format the post, assign a permanent slug if you omit one, add it to
`blogs/posts.js`, and push the updated site. Once published, keep the slug even
if the title changes so existing links continue to work.
